# slint-windows-mica-template

这是一个给 Windows 系统上的 Slint 添加了 **Mica 背景** 以及 **多屏居中弹出窗口** 的 Fluent Design 模板！✨

---

## 📖 关于本项目

第一次接触到 Slint 还是 Gemini 的推荐，一下子就被这个小巧精致的框架吸引了。

不过正式上手时感觉有点小遗憾：它没有提供开箱即用的居中弹窗，也没有 Fluent Design 的 Mica 效果和高仿 Win11 的无边框组件。

非常感谢 [@Drew-Chase](https://github.com/Drew-Chase) 开源的 [slint_borderless_windows](https://github.com/Drew-Chase/slint_borderless_windows)！为了方便修复一些细节问题，我直接将他的代码合并到了本项目中，在此特别感谢原作者的无私分享！🙏

---

## ✨ 这个项目做了什么？

1. **多屏智能居中弹窗**：利用 `winit` 后端获取句柄，让窗口直接从鼠标所在的屏幕中央弹出，完美避免窗口位置闪烁。
2. **Mica 视觉效果**：实现了 Win11 风格的 Mica 背景（暂时还没加 Acrylic 效果）。
3. **修复图标色块**：修复了原无边框组件中窗口化图标显示暗色色块的问题。
4. **补全窗口消息**：补充了额外的窗口消息，以便实现完整的窗口化/全屏化切换。
5. **平滑标题栏体验**：微调了 `titlebar` 逻辑，修复双击标题栏全屏/窗口化时，鼠标第一次点击出现的额外闪烁。

## ⚠️ 已知问题（踩坑记录）

### 1. NVIDIA 显卡 OpenGL 背景黑屏
* **踩坑经历**：在我的 GTX 1650 上，一旦使用 FemtoVG 的 OpenGL 后端渲染就会引发透明背景黑屏。（上帝，我真的被这个问题折磨了两三天！😭）
* **问题原因**：`NVIDIA 控制面板` -> `管理 3D 设置` -> `全局设置` -> `OpenGL GDI 兼容性`（“自动”或“优先性能”模式会引发透明效果黑屏）。
* **解决办法**：手动切换到 **“优先兼容性”**。
* **默认策略**：因为手头没有 AMD 和 Intel 显卡可以测试，为了保证大家拿到手就能开箱即用，框架**默认将渲染后端设置为 `software`**。

## 🚀 怎么用？

1. 克隆代码到本地。
2. **记得在 `Cargo.toml` 里把 `name = "..."` 字段修改成你自己的项目名！**
3. 运行 `cargo run` 即可。

## 📦 关于 Release 预编译包与杀软误报

这也是我第一次使用 CI/CD 流水线自动打包发布 `.exe`。

由于项目刚刚发布，且个人开源项目无法申请昂贵的数字签名证书，构建出来的 `.exe` 下载时大概率会被 Windows Defender 或杀毒软件提示为危险/误报毒。

* 如果你确实需要下载 Release 中的预编译 `.exe` 预览效果，可能需要临时关闭 Defender 的实时防护或手动选择允许运行。
* **更推荐的做法**：直接克隆本仓库并在本地执行 `cargo run`（本地编译绝对不会触发误报）。

希望这个小模板能帮到你！
